CMC VAULT — HIDDEN RECOVERY SHELL COMMANDS
==========================================

Public Help Commands
--------------------

HELP
  Shows the visible help list with ominous wording.

DIR
  Lists visible and fake hidden directories.

WHOAMI
  Returns unstable identity information.

STATUS
  Shows CRT diagnostics, vault status, and corruption readouts.

DATE
  Shows local time plus fake facility date information.

UPTIME
  Shows recovery shell uptime and fake long-term system uptime.

CLEAR
  Clears the terminal buffer.

LOGOFF
  Returns to the Secure Vault Access splash screen.


Recovery / Atmosphere Commands
------------------------------

ESCAPE
  Returns: "ESCAPE VECTOR NOT FOUND."

OPEN DOOR
  Returns: "PHYSICAL ACCESS DENIED."

LISTEN
  Plays faint static/audio chirps and reports distant sounds.

WAKEUP
  Briefly flickers the CRT and displays hidden-system flavour text.

SLEEP
  Powers the CRT display down briefly, then resumes.

HELLO
  Returns: "HELLO, MACREADY."

TRUST
  Returns: "REQUEST FLAGGED FOR REVIEW."

WHY
  Returns a random existential response.

WHEREAMI
  Displays fake facility coordinates and panic-room location data.

SIGNAL
  Reports a mysterious transmission and plays signal tones.

WAKE
  A more ominous wake command; the system stirs.

DREAM
  Displays corrupted dream-log flavour text.

FORGIVE
  Returns: "REQUEST TOO LARGE."

TRUTH
  Returns one random cryptic statement.

ERROR
  Simulates a terminal crash or confidence overflow.

STATIC
  Fills the terminal with static/noise lines.

MEMORY
  Shows old facility timestamps and log fragments.

TEST
  Returns: "TEST FAILED SUCCESSFULLY."


System / Feature Commands
-------------------------

ROOT
  Opens the PIN authorization screen.

UNLOCK
  Alias for ROOT; opens the PIN authorization screen.

CHESS
  Launches Chess Wizard.

RUN CHESS_WIZARD
  Launches Chess Wizard.

RUN CHESS_WIZARD.EXE
  Launches Chess Wizard.

GAME
  Returns: "WOULDN'T YOU PREFER A NICE GAME OF CHESS?" and launches Chess Wizard.

KINGME
  Launches Chess Wizard in corrupted mode.

AMBER
  Enables amber monochrome mode.

GREEN
  Restores green monochrome mode.

OVERRIDE
  Toggles the alternate UI colour state.

GLITCH
  Temporarily corrupts the CRT display.

SCANLINES
  Toggles CRT scanline intensity.

MIRROR
  Briefly inverts the CRT colours.

VOICE
  Toggles speech synthesis.

AUDIO
  Toggles synth boops/sound effects.

DEBUG
  Shows hidden system and chess statistics.

FPS
  Displays a fake performance monitor.

REBOOT
  Performs a fake hard CRT restart.

CLS
  DOS-style alias for CLEAR.
